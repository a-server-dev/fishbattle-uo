# uo

魚やウーパールーパーをバケツで捕まえて、属性（✊ / ✌ / ✋）を持たせた 1vs1 のじゃんけん＋連打バトルをする Paper プラグインです。魚の個体データ（属性・種族・レベル・経験値・HP）はバケツのアイテムに保存されます。

## 必要環境

- Paper サーバー
- Java 25（このリポジトリのビルド要件）

## ビルドと導入

リポジトリのルートで実行します。

```sh
./gradlew build
```

生成された `build/libs/fishbattle-uo-<version>.jar` をサーバーの `plugins/` に配置して起動します。初回起動時に `plugins/uo/` へ `config.yml` と `techniques.yml` が生成されます。

賭け金機能を使う場合は Vault と経済プラグイン（EssentialsX など）が必要です。無くてもバトル自体は動作します。

## 捕まえ方

1. **捕獲バケツ**を作る: バケツ + コンブ（作業台、形なしレシピ）
2. **捕獲バケツ**を手に持ち、タラ・サケ・フグ・オタマジャクシ・熱帯魚・ウーパールーパーを右クリックで捕まえる
3. 捕まえた魚は個体入りのバケツになり、そのまま持ち歩ける
4. 魚入りバケツを手に持って右クリックすると、目の前の頭の高さに魚を出せる（バケツは消える）
5. 出した魚は水流に乗るように出した人を追いかけて泳ぎ、無敵で窒息しない。出した魚は飼い主が殴るとバケツに戻ってインベントリに入る（空きがないと回収できない）
6. 出した魚を右クリックすると設定GUI（3行×9列）。**パラメータ**ボタンで強さ・体力・テクニック・EXPのバー画面（5行×9列）へ遷移し、「戻る」で設定へ戻る
7. **他人の魚**を右クリックすると閲覧用GUI（5行×9列）が開き、ステータスをバー表示・技を確認して「対戦を申し込む」から直接申し込める（賭け金100）
8. バトル中は魚・うおおじさんのGUIを開けない
9. 出したオタマジャクシは成長しない（カエルにならない）
10. 設定GUI右下の「逃がす」は2回クリックで確定（5秒以内）。魚は消えて野生に戻る（回収は不可）
11. フグだけ設定GUIの「ふくらませる」で ふつう → ふくらみ → 最大 を切り替えられる（見た目のみ。攻撃判定なし）

捕獲バケツと魚入りバケツは地面に落としても**燃えず・サボテンや溶岩でも消えず・消滅しません**（保護されます）。

普通の水入りバケツではバニラ通りにすくえます（個体データは付きません）。バトル用の個体にするには捕獲バケツを使ってください。捕獲バケツはクラフト（バケツ＋コンブ）または `/uo bucket` で入手できます。捕獲バケツでは水を汲んだりまいたりできません（消費されません）。魚を出すとバケツは空になります（捕獲バケツを使った場合も同様）。

## 属性（✊ / ✌ / ✋）

魚の属性はじゃんけんの手で表されます。属性はバトル中だけネームタグに表示されます。

| 属性 | アイコン | 強い相手 |
| --- | --- |
| ✊ グー | 鉄の原石 | ✌ チョキ |
| ✌ チョキ | ハサミ | ✋ パー |
| ✋ パー | 紙 | ✊ グー |

相性は 1.3 倍 / 0.75 倍です。ラウンドごとの手選択は別に残っており、属性はダメージ相性に効きます。


すべての魚（タラ・サケ・フグ・オタマジャクシ・熱帯魚・ウーパールーパー）は捕獲時に ✊ / ✌ / ✋ からランダムで属性が決まります。

種族（タラ・サケ・フグ・オタマジャクシ・熱帯魚の模様 12 種・ウーパールーパーの亜種 5 種）ごとに **強さ・体力・テクニック** の3値を持ちます。属性相性がダメージに効きます。

各3値には捕獲時に**個体値ランク**が付きます。

| ランク | 表記 | アイコン | 補正 |
| --- | --- | --- | --- |
| ダイヤ | ダイヤ(S) | ダイヤ | x1.10 |
| 金 | 金(A) | 金インゴット | x1.05 |
| 銅 | 銅(B) | 銅インゴット | x1.00 |
| 鉄 | 鉄(C) | 鉄インゴット | x0.95 |

捕獲時の抽選は ダイヤ5% / 金20% / 銅35% / 鉄40%。ランクは設定GUIのパラメータ画面と `/uo info` で確認できます。

種族値の合計が高い魚ほど必要EXPが増えます（`Lv×20 × 倍率`）。倍率は合計150で0.5、1ポイントごとに+0.08（下限0.45）。

- 合計150（タラ・サケ・フグ・オタマ）: 約15勝
- 合計155（ウパ）: 約22勝
- 合計160（熱帯魚）: 約30勝

種族値はサーバーの `plugins/uo/config.yml` で変更できます（`species.<id>.hp` / `power` / `technique` と `exp` セクション）。変更後は `/uo reload` またはサーバー再起動で反映されます。

捕獲時の初期レベルは **Lv1 30% / Lv2 40% / Lv3 20% / Lv4 10%** です。

## バトル（ムシキング式）

- `/uo demo`（管理者）で足元に**うおおじさん**を設置。村人の横には設定中の魚が並んで表示され、GUIで変えると見た目も即反映される。右クリックでGUIが開き、魚・レベル（1〜10）・属性・3値の個体値を変えて「バトル開始」できる。村人は倒されず消えない
- `/uo demo remove`（管理者）で**削除モード**をON/OFF。ONの間はうおおじさんを殴るとその村人だけ消える
- `/uo battle stop` でバトルを中断して終了（賭け金は返金）
- `/uo run` は降参扱い（相手の勝ち、賭け金は相手に渡る）
- 両者のuoの中間地点から32ブロック以上離れる、またはログアウトするとバトルは終了する
- 各ラウンド開始時に「手を選べ！」の表示から 0.5 秒後に手選択 GUI が開く（カウントダウンなし）
- バトルには**出している魚**が必要（魚入りバケツを右クリックして出す）。バケツのままでは戦えない
- `/uo battle [賭け金]` で近く（16ブロック以内）の全員に申し込み、`/uo battle <player> [賭け金]` で相手を指定（既定 100）
- 申し込みはチャットの `[受ける]` をクリックすると開始。クリック時にも相手との距離を確認する、相手が `/uo accept` で開始（`/uo deny` で拒否、60 秒で失効）
- 賭け金は Vault（EssentialsX）の残高から両者分を引き落とし、勝者が合計を受け取る。降参・離脱・ログアウトでは返金
- 各ラウンドは次の順で進む
  1. 両者が **✊ / ✌ / ✋** を選択。**GUI** が開くので、クリックで即確定（`/uo gu` 等のコマンドでも可）
     - 並び順は毎ラウンドランダムだが、両者に同じ順序で表示される
     - GUI を閉じた場合は開き直しを促され、**10秒で未選択ならランダムに自動確定**
  2. 両者の手を公開し、短い 3・2・1 のあと、**勝った側**と**あいこの両者**が **3 秒間連打**（`【連打】` をクリック、または `/uo mash`）して気合を溜める。装備した技が「連打時間 +1秒」を持っていれば延長される
  3. 勝った側が攻撃。あいこの場合は気合の差が1でもあれば差が大きい側が押し込み、威力は差に応じて軽減（完全に同値のときだけ選び直し）
- ダメージは攻撃側の気合・属性相性（1.3 倍 / 0.75 倍）・強さ・レベル・技・乱数で決まり、HP を削り合って 0 になった方が負け
- **技カードは ✊ / ✌ / ✋ の手ごとに1枚ずつ装備**でき、その手で勝ったときにだけ発動する（威力 1.00〜2.00 倍）
- 連打するのはそのラウンドの攻撃側（あいこは両者）だけ。守る側は連打せず、そのラウンドの気合を持たない
- 攻撃側の気合は威力に直結するので、連打を伸ばすほど大ダメージになる
- 気合の伸びやすさは**テクニック**で変わる（伸び率 = `テク/700`、0.03〜0.25、残り気合に比例）。3秒ではあえて上限に届かず、連打し続けるほど伸びる（毎秒10クリック時: テク30で約63%、テク60で約87%、テク70で約90%）。減衰は毎秒0.06
- `/uo run` で降参（相手の勝ち）
- 勝つと経験値が入り、一定量でレベルアップ（最大 Lv10）。レベルアップで最大 HP が増える。バトル終了時は両者全回復
- バトル終了後、両者の魚は HP 全回復する

## コマンドと権限

**全員（`uobattle.use`）**

| コマンド | 内容 |
| --- | --- |
| `/uo` / `/uo help` | コマンド一覧 |
| `/uo info` | 手持ちの魚の情報（個体値・HP・技・EXP） |
| `/uo battle [賭け金]` | 近く（16ブロック以内）の人に対戦申し込み（既定100） |
| `/uo battle <player> [賭け金]` | 相手を指定して申し込み |
| `/uo battle stop` | バトル中断（賭け金は返金） |
| `/uo accept` / `/uo deny` | 申し込みの受諾 / 拒否 |
| `/uo gu` / `/uo choki` / `/uo pa` | じゃんけんの手を選ぶ（GUIでも可） |
| `/uo mash` | 連打 |
| `/uo run` | 降参（相手の勝ち） |
| `/uo bucket` | 捕獲バケツを入手 |
| `/uo species` | 魚の種類一覧 |
| `/uo pet rename <name>` | 名前を変える |
| `/uo pet follow` | 追従 ON/OFF |
| `/uo pet collect` | 回収（バケツへ） |
| `/uo pet remove` | 魚を消す |
| `/uo pet train` / `/uo pet untrain <gu\|choki\|pa>` | 装備中の技を確認 / 外す |
| `/uo clear` | 自分が出した魚を消す |

**管理者（`uobattle.admin`）**

| コマンド | 内容 |
| --- | --- |
| `/uo demo` | 足元にうおおじさん（デモ村人）を設置 |
| `/uo demo remove` | 削除モード ON/OFF（ON中は殴った村人を消す） |
| `/uo reload` | `config.yml` / `techniques.yml` を再読込 |
| `/uo bucket <player>` | 他プレイヤーに捕獲バケツ |
| `/uo card <player> [技]` | 技カードを配布 |
| `/uo give <player> <species> [level]` | 魚を配布（species 例: `salmon` `cod` `tadpole` `KOB` `LUCY`） |
| `/uo clear all` | 全員の出した魚を消す |

| 権限 | 既定 | 用途 |
| --- | --- | --- |
| `uobattle.use` | 全員 | `/uo` 全般（対戦・捕獲・設定） |
| `uobattle.admin` | OP | うおおじさん・reload・give・card・bucket(他者)・clear all |

## 設定ファイル

`plugins/uo/config.yml` で種族値を変更できます。

```yaml
combat:
  damage-scale: 0.6   # 小さいほど長期戦（1.0で係数そのまま）
exp:
  reference-total: 150
  base-multiplier: 0.5
  per-point: 0.08
  min-multiplier: 0.45
species:
  cod:
    name: "タラ"
    hp: 60
    power: 45
    technique: 45
```

- `combat.damage-scale` はダメージ全体の倍率。0.6で平均3〜4ラウンド程度
- 3値の合計が大きいほど必要EXPが増えます（`exp` の設定が基準）
- 変更後は `/uo reload`（管理者）またはサーバー再起動で反映
- 記載のない種族は同梱の初期値が使われます

## 技カード（techniques.yml）

`plugins/uo/techniques.yml` で技カードを定義できます（初回起動時に自動生成）。

```yaml
techniques:
  wave:
    name: "ビッグウェーブ"
    hand: PA            # GU / CHOKI / PA
    power: 1.55         # 威力倍率
    mash-seconds: 0.0   # 連打時間の延長（秒）
    rarity: RARE        # COMMON / UNCOMMON / RARE / EPIC / LEGENDARY
    charge-start: 0.0   # 開始気合（0.15 = +15%）
    charge-gain: 1.0    # 気合の伸び倍率
    drain: 0.12         # 相手の気合を奪う割合
    pierce: 0.0         # 相手の気合防御を貫通する割合
    heal: 0.0           # 与ダメージのうち回復する割合
    ignore-type: false  # 属性不利を打ち消す
    tie-power: 1.0      # あいこの押し込み倍率
    flat-damage: 0      # 固定追加ダメージ
    description: "相手の気合を12%押し流す"
```

## うおおじさん（デモ村人）

`/uo demo` で置ける、設定可能なNPCです。

- 村人の横（頭の高さ）に、設定中の魚が並んで表示される。GUIで変えると即座に切り替わる
- 右クリックでベース画面（3行×9列）を開く
  - 魚（21種）、レベル（1〜10）、属性（✊/✌/✋）、強さ・体力・テクの個体値（S/A/B/C）を左右クリックで変更
  - 表示されるHP・強さ・テクは実際の値を反映
- 「バトル開始」で、村人の3ブロック前を中心にバトル開始。横の魚をそのまま使うため2匹にはならない
- 村人は無敵・消えない。`/uo demo remove` で削除モードにすると、殴った村人を消せる（横の魚も一緒に消える）

## データ

個体データはアイテムやエンティティの PersistentDataContainer に保存されるため、追加のデータファイルはありません。
